## 诊断结论

### 根因分析

`pagination.py` 中的 `page_count` 函数实现为：
```python
return total_items // page_size + 1
```

这个公式对**所有** `total_items` 值都无条件加 1，导致两个问题：

1. **当 `total_items` 恰好是 `page_size` 的整数倍时**（如 20 个物品、每页 10 个），应该正好 2 页，但当前实现返回 `20 // 10 + 1 = 3`，多了一页。
2. **当 `total_items == 0` 时**（空集合），应该需要 0 页，但当前实现返回 `0 // 10 + 1 = 1`，多算了一页。

正确的公式应使用**向上取整除法**：`(total_items + page_size - 1) // page_size`，或者等价地用 `math.ceil(total_items / page_size)`。这样：
- `0` → 0 页 ✓
- `20` → 2 页 ✓
- `21` → 3 页 ✓
