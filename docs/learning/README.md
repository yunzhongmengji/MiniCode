# MiniCode 学习笔记索引

这里保存可以重新学会某个模块的中文笔记，而不只是开发进度。

## 文档分工

| 位置 | 记录内容 | 回看时解决的问题 |
|---|---|---|
| 源码 docstring | 模块、类、函数的职责和接口 | “这段代码是做什么的？” |
| 源码行内注释 | 不明显的原因、安全边界和取舍 | “为什么必须这样写？” |
| `tests/` | 输入、输出和错误路径的可执行例子 | “它应该怎样表现？” |
| `docs/learning/` | 中文概念、调用链、语法和练习 | “我忘了以后怎样重新学会？” |
| `docs/adr/` | 重要架构选择、替代方案和后果 | “当初为什么选择这个设计？” |
| `docs/LEARNING_LOG.md` | 掌握证据和复习状态 | “我学到了哪里？” |

不会给每行代码添加中文翻译。重复代码表面含义的注释会很快过期，也会遮挡真正重要的逻辑。注释优先解释约束、风险和不直观的原因。
